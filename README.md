# SG–MY Cross-Border Dashboard

Live at **https://sgmydash.backkampung.com**

A single static page for Singapore–Malaysia travellers: Causeway checkpoint
conditions, SGD→MYR rates (CIMB vs Wise with a fee calculator), weather for
Singapore / Johor Bahru / Muar, Singapore PSI by region, and SG + Malaysia
(+ Johor) holidays with the next long weekend highlighted.

## How it stays fresh

- **FX rates** — the page fetches live rates from a small Cloudflare Worker
  (`sgmy-fx-rates`, see `../fx-worker.js` — not in this repo) on every page
  open. The Worker fetches Wise and CIMB server-side, where CORS does not
  apply. `rates.json` in this repo is the fallback when the Worker omits a
  rate or is down; it is written every 5 minutes by the FX workflow.
- **Checkpoints, weather, PSI, holidays** — `data.json`, rewritten hourly by
  the data workflow. The page re-checks every 30 minutes while open, and
  holidays again at midnight.
- **Refresh button** — on the Send card, dim and disabled while the rate is
  fresh, lit and clickable once it is over 5 minutes old. FX never
  auto-refreshes.

## Sources (quoted on every card)

| Card | Source |
| --- | --- |
| Checkpoints | LTA DataMall Traffic Speed Bands v4 + Traffic Incidents (free API key, stored as a Secret). Approach-road speed bands only — **not** immigration clearance time, and no public source publishes clearance times. Singapore side only. |
| Send SGD→MYR | CIMB Singapore board rate, scraped from the `rateList` field at cimbclicks.com.sg/sgd-to-myr (zero fees); Wise live mid-market rate from wise.com/rates/live, used unrounded. |
| Weather | OpenWeather (key as a Secret), Singapore / Johor Bahru / Muar. |
| PSI | data.gov.sg `v1/environment/psi`, no key. |
| Holidays | Nager.Date for Singapore (national only); Malaysia federal and Johor state holidays are curated files — Nager.Date does **not** cover Malaysia (`/MY` returns HTTP 204). |

## Wise fee formula

The calculator's fee is locked, not user-editable. It was fitted from five
Wise app screenshots (bank-account funding, SGD 100–2,000, Nov 2026):

- Our fee = (0.54 + 0.0025 × amount) ÷ 1.0025, rounded to cents
- VAT = 8% of Our fee, rounded to cents

Verify in the Wise app before sending. Wise can change or tier its fees.

## Setup (first time)

1. Create the repo (done: `backkampung/sgmydash`, public).
2. Add two Secrets — Settings → Secrets and variables → Actions:
   `OPENWEATHER_API_KEY` (the key Charlie uses) and `LTA_API_KEY`
   (register free at datamall.lta.gov.sg). Never paste keys in chat or
   in any file; the workflows reference only the secret names.
3. Paste the two workflow files (`.github/workflows/`) via the GitHub web
   UI — the API cannot push workflow files (403).
4. Settings → Pages → Build and deployment → Source: Deploy from a branch,
   Branch: `main`, Folder: `/ (root)`. Add the custom domain
   `sgmydash.backkampung.com` there, and in DNS a CNAME record
   `sgmydash` → `backkampung.github.io`. Then enforce HTTPS.
5. Deploy the Cloudflare Worker from `fx-worker.js` (2 minutes, free) and
   put its URL in the `WORKER_URL` constant at the top of `index.html`.

## Notes

- No secrets or keys anywhere in this repo. Keys live only as GitHub
  Secrets (used server-side by the workflows) and in Cloudflare.
- CIMB's rate is scraped from its page: if CIMB changes the layout, the
  fetcher keeps the last-known rate with its timestamp and fails loudly
  in the workflow log.
- GitHub Actions cron floor is 5 minutes; runs can be delayed under load.
  Workflows commit only when their output file changed.
- Holiday dates marked with a note are subject to official announcement
  (moon sighting). Update `data/my-holidays-*.json` and
  `data/johor-holidays.json` once a year from the gazette.
