# SG–MY Cross-Border Dashboard

Live at **https://sgmydash.backkampung.com**

A single static page for Singapore–Malaysia travellers: Causeway checkpoint
conditions, SGD→MYR rates (CIMB vs Wise with a fee calculator), weather for
Singapore / Johor Bahru / Muar, Singapore PSI by region, and SG + Malaysia
(+ Johor) holidays with the next long weekend highlighted.

## How it stays fresh

- **FX rates** — fetched live on every page open from a small serverless
  proxy, which reads Wise and CIMB server-side. `rates.json` in this repo
  is the fallback; it is refreshed every 5 minutes.
- **Checkpoints, weather, PSI, holidays** — `data.json`, refreshed hourly.
  The page re-checks every 30 minutes while open, and holidays again at
  midnight.
- **Refresh button** — on the Send card, dim and disabled while the rate is
  fresh, lit and clickable once it is over 5 minutes old. FX never
  auto-refreshes.

## Sources (quoted on every card)

| Card | Source |
| --- | --- |
| Checkpoints | LTA DataMall Traffic Speed Bands v4 + Traffic Incidents. Approach-road speed bands only — **not** immigration clearance time, and no public source publishes clearance times. Singapore side only. |
| Send SGD→MYR | CIMB Singapore board rate, scraped from the `rateList` field at cimbclicks.com.sg/sgd-to-myr (zero fees); Wise live mid-market rate from wise.com/rates/live, used unrounded. |
| Weather | OpenWeather, Singapore / Johor Bahru / Muar. |
| PSI | data.gov.sg `v1/environment/psi`, no key. |
| Holidays | Nager.Date for Singapore (national only); Malaysia federal and Johor state holidays are curated files — Nager.Date does **not** cover Malaysia. |

## A note on the Wise calculator

The rate shown is an estimate — the rate you get in the Wise app may differ
slightly. Check in the Wise app before sending.

## Repo layout

```

CNAME                             sgmydash.backkampung.com
data.json / rates.json            generated by the workflows (committed)
scripts/fetch-data.py             checkpoints, weather, PSI, holidays → data.json
scripts/fetch-fx.py               Wise + CIMB → rates.json
data/my-holidays-2026.json        Malaysia federal holidays, curated
data/my-holidays-2027.json        (Prime Minister's Department schedule)
data/johor-holidays.json          Johor state holidays, curated
data/sg-replacements.json         Singapore observed-day holidays, curated
.github/workflows/update-data.yml hourly data refresh
.github/workflows/update-fx.yml   FX refresh every 5 min
```

## Notes

- No secrets or keys anywhere in this repo.
- CIMB's rate is read from its public page: if CIMB changes the layout,
  the fetcher keeps the last-known rate with its timestamp.
- Holiday dates marked as provisional are subject to official announcement
  (moon sighting).
